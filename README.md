# Power BI Dashboards

A collection of Power BI dashboards built while practising data modelling, DAX and report design.

## Projects

| Folder | Dashboard | Dataset |
|---|---|---|
| [`first basics`](first%20basics) | `firstbasic.pbix`: introductory sales dashboard | Global Superstore (`GlobalSuperstore.xlsx`) |

## How to open

1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows).
2. Download the `.pbix` file and open it.
3. If prompted, point the data source to the `.xlsx` file in the same folder.
